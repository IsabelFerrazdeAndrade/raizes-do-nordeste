# Raízes do Nordeste

Raízes do Nordeste é um projeto acadêmico de uma aplicação web
para uma rede fictícia de lanchonetes inspirada na culinária nordestina.

O site permite simular um pedido, desde a escolha da unidade e dos
produtos até o pagamento e o acompanhamento do preparo. Também possui
um modo Totem para demonstrar o autoatendimento.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- localStorage

## Principais funcionalidades

- Seleção de unidade.
- Cardápio com busca, categorias e promoções.
- Detalhes dos produtos.
- Carrinho com controle de quantidade e cálculo do total.
- Cadastro e login demonstrativos.
- Informações de privacidade/LGPD, preferências de marketing e exclusão de dados locais.
- Pagamento simulado com Pix ou cartão.
- Acompanhamento de pedidos com simulação das etapas de preparo.
- Fidelidade com pontos e resgate de recompensa demonstrativa.
- Modo Totem para autoatendimento.
- Layout responsivo para celular e desktop.

## Como executar

Abra o arquivo `index.html` diretamente no navegador.

Se preferir, abra a pasta do projeto no VS Code e utilize a extensão
**Live Server** para executar o site.
